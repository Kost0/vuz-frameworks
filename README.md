# vuz-frameworks — ПР3

Консольное приложение для планирования обучения и отслеживания прогресса по курсам и темам.

## Что изменено в ПР3

Проект переведён с функциональной модели `dict/list[dict]` на объектную модель.
Основные сущности представлены классами:

- `User` — пользователь системы;
- `Course` — учебный курс;
- `Theme` — тема курса;
- `Progress` — прогресс конкретного пользователя по конкретному курсу.

### Связи объектов

```text
User
 └── Progress
      ├── User → пользователь
      └── Course → курс
                    └── Theme[] → темы курса
```

Один пользователь может иметь несколько объектов `Progress`, по одному на курс. `Progress` хранит множество идентификаторов завершённых тем. Благодаря этому прогресс не является свойством самого курса и может отличаться у разных пользователей.

## Основные методы

### User

- `__init__()` — создание пользователя;
- `add_progress()` — добавление прогресса;
- `get_progress()` — получение прогресса по курсу;
- `__str__()` — строковое представление;
- `from_data()` — создание объекта из JSON-данных.

### Course

- `__init__()` — создание курса;
- `add_theme()` — добавление темы;
- `get_theme()` — поиск темы;
- `calculate_progress()` — расчёт процента прохождения;
- `__str__()`;
- `from_data()` / `to_data()`.

### Theme

- `__init__()`;
- `__str__()`;
- `from_data()` / `to_data()`.

### Progress

- `mark_theme_completed()` — отметить тему пройденной;
- `is_theme_completed()` — проверить состояние темы;
- `calculate_percent()` — получить процент прохождения;
- `__str__()`;
- `to_data()`.

## JSON

Для сохранения объектной модели используются три файла:

- `data/courses.json` — курсы и темы;
- `data/users.json` — пользователи;
- `data/progress.json` — связи пользователя с курсом и завершённые темы.

JSON не хранит внутренние Python-объекты. При загрузке создаются объекты `Course`, `Theme`, `User` и `Progress`, а перед сохранением они преобразуются в обычные JSON-данные.

Формат старого `courses.json` сохранён совместимым: поля `name`, `themes`, `is_completed` по-прежнему читаются. Состояние выполнения теперь является ответственностью `Progress`.
