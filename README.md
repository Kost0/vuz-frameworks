# vuz-frameworks

Консольное приложение для планирования обучения и отслеживания
прогресса по курсам и темам.

## Возможности

- просмотр списка курсов с процентом прогресса;
- добавление курса с набором тем;
- просмотр статуса конкретной темы;
- отметка темы как пройденной;
- поиск курсов по подстроке названия;
- отбор курсов с прогрессом не менее заданного процента;
- сортировка курсов по проценту прогресса.

## Структура проекта

```
vuz-frameworks/
├── README.md
├── requirements.txt
├── main.py        — точка запуска, меню приложения
├── courses.py      — функции для работы с курсами и темами
├── storage.py      — сохранение и загрузка данных (JSON)
├── utils.py        — безопасный ввод данных пользователем
├── data/
│   └── courses.json — данные о курсах
└── tests/
    └── test_courses.py — автоматизированные тесты
```

## Формат данных

Курсы хранятся в файле `data/courses.json` в виде словаря, где ключ —
идентификатор курса (строкой, как того требует JSON), а значение —
данные курса:

```json
{
  "1": {
    "name": "Разработка на Python",
    "themes": [
      {"name": "Переменные", "is_completed": true},
      {"name": "Циклы", "is_completed": false}
    ]
  }
}
```

Каждая тема — словарь с названием и признаком `is_completed`.

## Требования

- Python 3.10+
- pytest
- flake8

Установка зависимостей:

```
pip install -r requirements.txt
```

## Запуск программы

```
python main.py
```

## Запуск тестов

```

```

