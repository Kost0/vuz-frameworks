# vuz-frameworks

Консольное приложение для планирования обучения и отслеживания прогресса по курсам и темам.

## Возможности

- просмотр списка курсов с процентом прогресса;
- добавление курса с набором тем;
- просмотр статуса конкретной темы;
- отметка темы как пройденной;
- поиск курсов по подстроке названия;
- отбор курсов с прогрессом не менее заданного процента;
- сортировка курсов по проценту прогресса;
- хранение пользователей и их прогресса по курсам;
- сохранение и загрузка данных в формате JSON.

## Объектная модель

В ПР3 проект переведён с функциональной модели на объектную модель. Основные
сущности предметной области представлены классами:

- `User` — пользователь системы;
- `Course` — учебный курс;
- `Theme` — тема курса;
- `Progress` — прогресс конкретного пользователя по конкретному курсу.

Связи между объектами:

```text
User
 └── Progress
      ├── User → пользователь
      └── Course → курс
                    └── Theme[] → темы курса
```

Один пользователь может изучать несколько курсов, поэтому у пользователя
может быть несколько объектов `Progress`. Для одного курса разные пользователи
могут иметь разный прогресс.

### User

Основные методы:

- `__init__()` — создание пользователя;
- `add_progress()` — добавление прогресса по курсу;
- `get_progress()` — получение прогресса по курсу;
- `__str__()` — строковое представление объекта;
- `from_data()` — создание объекта из JSON-данных.

### Course

Основные методы:

- `__init__()` — создание курса;
- `add_theme()` — добавление темы;
- `get_theme()` — поиск темы по идентификатору;
- `calculate_progress()` — расчёт процента прохождения;
- `__str__()` — строковое представление объекта;
- `from_data()` / `to_data()` — преобразование объекта в JSON-данные и обратно.

### Theme

Основные методы:

- `__init__()` — создание темы;
- `__str__()` — строковое представление объекта;
- `from_data()` / `to_data()` — преобразование объекта в JSON-данные и обратно.

### Progress

Основные методы:

- `mark_theme_completed()` — отметить тему пройденной;
- `is_theme_completed()` — проверить состояние темы;
- `calculate_percent()` — получить процент прохождения курса;
- `__str__()` — строковое представление объекта;
- `to_data()` — преобразование объекта в JSON-данные.

## Формат данных

Курсы хранятся в файле `data/courses.json` в виде словаря, где ключ —
идентификатор курса (строкой, как того требует JSON), а значение — данные
курса:

```json
{
  "1": {
    "name": "Разработка на Python",
    "themes": [
      {"id": 1, "name": "Переменные"},
      {"id": 2, "name": "Циклы"}
    ]
  }
}
```

Пользователи хранятся в `data/users.json`:

```json
{
  "1": {
    "name": "Иван",
    "email": "ivan@example.com"
  }
}
```

Прогресс пользователей хранится в `data/progress.json`. Он связывает
пользователя с курсом и содержит идентификаторы завершённых тем:

```json
{
  "1": {
    "user_id": 1,
    "course_id": 1,
    "completed_themes": [1]
  }
}
```

JSON не хранит внутренние Python-объекты. При загрузке данные преобразуются
в объекты `User`, `Course`, `Theme` и `Progress`. Перед сохранением объекты
преобразуются обратно в обычные структуры данных, совместимые с JSON.

## Работа с JSON

Данные загружаются из каталога `data/` при запуске приложения. После работы
с объектами данные могут быть сохранены обратно в JSON.

Таким образом, переход к объектной модели не изменяет назначение приложения:
пользователь по-прежнему может работать с курсами и темами, а данные сохраняются
между запусками программы.
