# vuz-frameworks

## Назначение

Сервис предназначен для планирования обучения и отслеживания прогресса по курсам и темам.

## Целевая аудитория

Студенты, преподаватели, самообучающиеся специалисты и сотрудники учебных центров.

## Предметная область

Организация учебного процесса: управление курсами, темами и прогрессом пользователей.

## Основные сущности
- Пользователь
- Курс
- Тема
- Прогресс

## Основные функции
- Добавить курс
- Просмотреть тему
- Пометить тему пройденной
- Посмотреть прогресс по курсу

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
